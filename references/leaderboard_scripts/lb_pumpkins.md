## 收益机制说明

- 南瓜和胡萝卜一样，必须种在耕过的地 / Soil 上，而且种植会消耗胡萝卜。
- 南瓜榜的关键机制不是 companion，而是“方形区域内全部南瓜同时完全成熟后，会合并成一个巨型南瓜”。
- 这里有两个必须写死的规则：
  - 只要方形区域里有一个南瓜没有成熟，就不会合并
  - 只要方形区域里有一个南瓜枯死变成 `Dead_Pumpkin`，也不会合并
- 多无人机南瓜可以用任意一组对角判断整块是否已合并成熟：
  - 选任意一个角作为角 1
  - 对角作为角 2
  - 当 `measure(角1) == measure(角2)` 时，可以视为这块已经形成同一个 giant pumpkin，可以收割
  - 这比全块逐格扫描 `can_harvest()` 更适合作为整块成熟判定
- 南瓜在完全成熟后有 `20%` 概率枯死：
  - 枯萎南瓜不会掉任何东西
  - 枯萎南瓜不会参与合并
  - 它还会阻止周围南瓜合并
  - 但在枯萎南瓜上直接种新作物会自动移除它，所以不需要先 `harvest()` 掉枯萎南瓜
- 南瓜产量规则是：
  - `1x1 -> 1*1*1 = 1`
  - `2x2 -> 2*2*2 = 8`
  - `3x3 -> 3*3*3 = 27`
  - `4x4 -> 4*4*4 = 64`
  - `5x5 -> 5*5*5 = 125`
  - `n>=6` 时变成 `n*n*6`
- 这条规则直接推出：
  - 单块南瓜的最佳尺寸就是 `6x6`
  - 因为 `6x6` 开始已经触发封顶倍数，继续增大单块并不会提高单位面积收益

## 当前已知解法

- 单块最优尺寸已经很明确：`6x6`
- 多无人机当前已知解法不是“全图切成一堆 6x6”，而是：
  - 两个 `8x8`
  - 两个 `6x6`
  - 每片 `2` 个无人机
- 你给出的当前参考视频是：
  - `https://www.bilibili.com/video/BV1phsUzXEH9`
- 这套布局看起来诡异，但你给出的当前理解是：
  - 不是 `8x8` 本身比 `6x6` 单块效率更高
  - 而是单纯用 `6x6` 方案时，地盘至少要到 `13x13`
  - 但 `8x8 + 6x6` 混排时，两个 `8x8` 各占一个角，中间只留一个单格连接
  - 单格不可能长成大南瓜，因此可以把无效连接空间压到最低
  - 这样整体只需要 `16x16` 的地盘
- 你当前的进一步猜测是：
  - 最优摆法可能是让 `8x8` 和 `6x6` 都尽量放在四个角
  - 这样可以尽量减少起步时间
- 这部分先作为当前已知解法记录，不在本轮继续发散成更多块尺寸猜测
