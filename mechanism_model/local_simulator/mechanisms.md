# 全作物机制与近似边界

本地脚本模拟已适配基础游戏的12种实体，其中7种可直接种植。目标是读取同一脚本，在单个seed下尽量复刻资源、随机轨迹和时间；精度门槛见[模拟精度与验收](../README.md#模拟精度与验收)。本地报告始终是 `prediction`，筛出候选后仍须真实游戏打榜。

当前实现对应的游戏版本、源码变化和未验证项见[更新对齐记录](game-update-26385848.md)。下表中的历史对照结果对应旧版Core，当前实现尚未完成新版实机验收。

## 覆盖范围

| 实体或机制 | 本地实现与短场景对照 |
| --- | --- |
| 草、灌木、树、胡萝卜 | 生长、地面要求、成本、成熟/未成熟收获、伴生目标及收益倍率 |
| 树木邻接 | 四邻树各使成熟时间加倍；种树、移除树、浇水/施肥和邻格成熟按事件刷新计时 |
| 南瓜、死亡南瓜 | 种植编号、成熟死亡概率、死亡后覆盖重种、最大兼容正方形合并、整组删除、感染收益；2×2、3×3、6×6、7×7收益对照 |
| 向日葵 | 7～15花瓣、满10株时最大花瓣8倍资格、全田上次错收标记；施肥感染后的Power/奇异物质分配 |
| 仙人掌 | 数字缓存、成熟、交换、排序连锁、感染收益；保留既有方法级回归 |
| 苹果、恐龙 | 恐龙帽、DFS空格列表抽样、末果观测、离开苹果格时吃苹果、移动成本递减、尾巴/边界碰撞、换帽结算及替代植物保留 |
| 树篱、宝藏 | 独立maze流生成墙壁和宝藏、移动受墙约束、宝藏收益、再利用后迁移与开墙、迁移中禁收、归属检查、移除整座迷宫、迷宫下翻地 |
| 水、肥料、感染、补给 | 水量封顶和逐次随机衰减、加速生长、肥料推进成熟、本格/邻格感染切换、周期水肥补给 |

| 多无人机 | 农田/库存共享，位置/随机流/全局变量/闭包副本独立，返回值复制，等待与清场取消 |

南瓜收益为 `边长² × min(边长, 6) × 科技产量倍率`；感染部分按原版分给奇异物质。伴生只要求目标格实体类型符合，不要求伴生作物成熟。普通装饰帽可使用，但不模拟Steam成就或外观拥有条件。

向日葵的当前错收规则见[更新对齐记录](game-update-26385848.md#对打榜的影响)。以下保留旧版Core的实机证据，不能作为新版丢花或乱序收割的收益依据。

### 旧版Core：2026-10-30错收调用链与实机证据

旧版Core（SHA256前缀`b8ac8d22`）的`Sunflower.Harvest`存在错收标记被后续虚调用覆盖的行为。该版Core1803–1817先设置标记并可能关闭`getBoost`，随后进入`Growable.Harvest`（1222–1228）；其中的虚`GetYield()`调用进入`Sunflower.GetYield`（1820–1824），再次按最高瓣且至少10株重设`getBoost`，覆盖了前面的收益标志。视觉效果不在本地模型范围内。

新鲜同源seed1方法对照request222：成熟低瓣1→最高瓣8→最高瓣8；成熟低瓣1→普通草收割→最高瓣8；成熟低瓣1→未成熟低瓣移除0→最高瓣8。8条花瓣数、成熟状态、Power增量和调用tick记录与模型逐字一致，总tick均69484。本地阶段11.43776124秒，实机显示11.44秒，符合两位小数展示精度；不能把舍入差当精确计时误差。双日志无错误/异常，idle222恢复原test.py/simulate.py，游戏保持开启。

当时模型不额外施加错收产量惩罚，对应的丢花/独立区域报告只对该旧版有效。此对照只覆盖列出的边界，不代表全部并发或长程精度。证据`.codex/leaderboard-astra/sunflowers-incorrect-harvest/`：执行源`452f5c6a69e791d5e39bc690f59ce4442e371101f784765e979d9a7278c13e97`，实机报告`e6081addd75e09b806e04e7bd15354abe5ad76eb5e6f206095f77ea55949aec5`，本地报告与模型world.py SHA保存在analysis.json。

## 计时实现与待验证边界

- 成熟事件保留原版Single随机倍率、纳秒截断和同刻四叉堆顺序。`various`的实体旋转、感染外观及逐格水分抽取消耗均接入；新版遍历顺序与初始化已更新，实机轨迹尚待对照。历史差异见[验收记录](validation.md)。
- 水分每0.1游戏秒逐格随机衰减，零水格也抽取；生长倍率改变时重排成熟事件。
- 脚本表达式和容器操作计入tick，执行器按199t批次推进，在共同操作时刻按无人机编号应用副作用。
- Power每0.2秒结算批次操作消耗；旧版已对照向日葵首次获得及长场景耗尽；新版补上恰好耗尽边界，任意并发等待组合未全面验证。
- `preset=reset` 提供低科技初始场景和升级机制，不代表已验证完整Fastest Reset流程。游戏语言的非整数range、全部解锁语法门槛、极端类型组合和任意无人机竞态仍未全面复刻。模拟内部不启动嵌套simulate或leaderboard。
- 报告无统一“误差百分比”。成熟等待密集、纯计算密集、复杂竞争或候选差距接近误差时，应增加seed并交给短程实机判断。
