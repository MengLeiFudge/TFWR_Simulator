# 成就脚本

本目录保存全科技下的一次性成就入口。脚本与文件同名，完成对应任务后退出。

| 成就 | 入口 | 行为 |
| --- | --- | --- |
| 彩色金字塔 | [power_pyramids_color.py](power_pyramids_color.py) | 6×6田寻找最小天然塔，保留基座，拆净后用35块彩色地块重建一座 |

## 彩色金字塔

独立运行 `power_pyramids_color.py`。入口会清场并把本次执行的地图限制为6×6，首次使用一次 `jump(Unlocks.Pyramid)`。直接启动整个脚本，避免在已经用过Jump的执行中调用。

天然金字塔最小底边为5×5；5×5及更小的地图不生成塔。6×6地图生成的塔只能为5×5。原址塔体需要25＋9＋1＝35块，红、绿、蓝地块可以混用，全部使用同一种彩色地块也满足材料判定。沙块与彩色地块混用不能完成复原。

脚本在地图中心下挖到石灰岩基座，再把全田清理到相同高度。基座必须恰好组成5×5矩形，才开始重建。修建阶段只放块，顶块最后放置；游戏清除塔体并生成成熟向日葵后，脚本收获并退出。Block不足35、移动或挖掘失败时会报告原因并停止。

找塔最多尝试16片，每片探到z＝−128；探孔和拆塔共用600游戏秒截止时间。只有首次找塔使用Jump，换田不会再次跳跃。

## 其他地下成就的判定

| 成就 | 判定与限制 |
| --- | --- |
| 远距离友谊 | 一次同色配对的两块蘑菇必须来自不同的原生地层；同一片蘑菇内的不同z高度不算跨地层 |
| 牵线搭桥 | 同一原生地层累计配对块数除以生成时该片的原始蘑菇总数，必须严格大于95%；分母包含整片厚度，挖掉和塌掉的块不会减少分母；跨地层配对不增加此计数 |
| 采矿大师 | 目标为60游戏秒内获取1,000,000 Block，约需16,666.67 Block/游戏秒；评估时应保留具体60秒窗口，不能用长期平均速率代替窗口结果 |

蘑菇条件来自 `MushroomController.OnAfterPush` 与 `OnChunksAddedOrRemoved`；金字塔条件来自 `PyramidFeature.GetProbability/Generate` 与 `PyramidController.IsPyramidComplete/ClearPyramid`。对应源码见[游戏反编译事实源](../../references/DecompiledSource/Core/Core.decompiled.cs)。本次已只读核对安装程序集中的同名类型，Core.dll SHA256为 `f0efda7c138de8028b1769c121a4b5c17b6bb538aeae5a67d1881e7c4ebd7d25`。
