**核心算法（2026-11-25 架构重写，承接单机突破并针对 32 机并发优化）**：
1. **5/6 层选场 + 5 层二叉树并发派工**：主机在 `(0,0)` 挖穿覆盖层并接受 `height >= 5`（将串行拒场重掷减半）；通过 `tree_worker` 二叉树 5 级派工（0.16 秒启动全部 32 机，取代线性 31 次串行派工的 1.02 秒），且将距 `(0,0)` 最远的区块排在右半树率先出发。
2. **4×8 分区 16 格内部 U 型多米诺塌方揭盖**：每机负责独立 4×8（32 格）分区，仅在入场格 `(bx+1, by)` 挖穿覆盖层，随后沿内部两列 `x=bx+1`、`x=bx+2` 走 16 格 U 型脊线，每格挖 1 块蘑菇（238t）利用覆盖层 `autodestroyWhenDugBeside=1` 自动塌平左右外列 `x=bx`、`x=bx+3`，同时单次读取全部 32 格 `(z, color)`，0 额外移动且无东西跨界挖掘。
3. **共享时间截止线消除 32 机长尾屏障**：旧版 `v1` 无截止线时 `wait_for` 累计空等达 24.57 秒（31 机等最慢 1 机尾段）；本版按层高下发共享 `deadline`（6 层 `14.0s`、5 层 `11.0s`），全部 32 机同步收口换场，将 `wait_for` 尾损压至极低；仅在库存达到 195k 后的终局批次才检测 240k 目标，避免前期批次高频调用 `num_items()`。
4. **模块级静态拓扑 + 哨兵槽 32 + 跨区塌方自愈**：4×8 邻接表 `N0..N3` 与坐标表 `CX/CY` 静态预置（每场 0t 重建），越界邻格统一指向哨兵槽 `32`（`c=-2, z=9999`），热路径彻底省去 `nb >= 0` 边界分支；匹配阶段采用“单次四邻合并直推/反推 + 展开式过桥/汇合 + LIFO 就绪边栈 + 距离 ≥3 原地 0 移动异色堆叠蓄色 + `O(1)` 环形游标兜底”（并取消了 4×8 小区净负收益的 `d=1` 邻格前推）；每次 `push` 与 `measure` 均带极轻自愈回读 `resync_pair`，彻底免疫极罕见的南北边界跨机延迟塌方（63/63 完整轮 0 失败 0 警告）。
