## 当前实现与正确性边界

`scripts/functional/cactus.py`的`sort_one_way`保留原有三格排序、往返扫描、边界收缩和末尾两格处理，只减少重复查询和边界计算。

每次开始单向扫描时重新读取起点两格，前移一格后沿用重叠的两格，只测量新进入窗口的一格。窗口内部交换后同步维护后续仍会读取的值；正向最后一次向后交换只需更新`b = a`，反向对应为`b = c`。下一窗口用标量赋值传递两个值，避免整组三元组搬运抵消节省的查询成本。

这个复用只在同一条线的一次单向扫描内有效，不跨行、跨方向、跨坐标轴或跨批次。行阶段每个工人独占一行，全部行工人回收后才开始列阶段；列阶段每个工人独占一列，因此其他工人不会修改当前缓存的仙人掌。原版移植模型的`Cactus.Measure()`返回实体的`number`；`OnFullyGrown()`只清除格子的后续种植缓存，不改变当前实体的大小。交换会搬移实体，窗口中的缓存按相同交换更新。这些边界来自`simulator/headless/Native/World.cs`的`Cactus`实现。

同时用直接赋值替换扫描边界的`max`/`min`：正向索引`i`递增，前一窗口记录的最大位置不超过当前`i`；同一窗口的两次记录依次为`i`、`i + 1`，直接覆盖等价于取最大值。反向索引递减，对`i`、`i - 1`同理。边界收缩公式不变。
