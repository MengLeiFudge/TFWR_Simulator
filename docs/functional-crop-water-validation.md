# 常规地上作物：一次补满水位

2026-11-12。全科技含DLC、普通32×32田、32台无人机、19项材料各10亿；生产一种资源时其他材料足够。效率使用目标资源实际净增长÷实际游戏秒×60，包含初始化、伴生准备、移动、成熟、合并结算和回收，不另计生产水或肥料。每例预设10墙钟秒，最多两例并行；39份报告最长2.06墙钟秒。

## 实现

`wood.work_drone_task`、`carrot.work_drone_task`和`pumpkin.work_drone_task`在原有补水位置，一次使用四桶水。三个补水阈值仍分别为0.35、0.15、0.80，原有库存大于32的判断继续为并发调用保留余量。木材和胡萝卜使用原有伴生请求，南瓜使用原有区域助手、两栈成熟队列及肥料逻辑；目标参数继续传给所有工人，正常回收后才结束。

原版成功的`use_item(Water, 数量)`按一次浇水动作计费，一桶和四桶在该项动作费用相同。常规生产材料充足时，一次补足水位可减少成熟等待及后续补水。三个入口分别比较，未把[水稻结果](functional-rice-water-validation.md)直接当作它们的证据。迁入排行榜前仍须核对对应场景的供水时点与库存，尤其是从零开始的重置榜。
