# 常规水稻：充足库存下补满水位

2026-11-12。普通32×32田、全科技含DLC、32台无人机，19项资源各10亿；生产水稻时其他材料充足。实际净增长除以实际游戏时间，计入清场、探挖、种植、移动、成熟和子机回收，不另计获取水的时间。每例10墙钟秒、最多两例并行，13份报告最长1.13墙钟秒。

## 改动与适用条件

`rice.rice_columns`保留每列唯一写者的两层流水。两次实际种植后，水位低于0.75且库存至少四桶时，一次使用四桶水；替代原来低于0.25时只用一桶的方式。第一次收割成功后才下挖，实际露出下一层Clay才重种，全部子机回收后才清场。

原版`Execution.UseItem`对成功的Water使用按一次动作计费；`Drone.Water`按数量增加水位。常规库存充足时，多桶水可以在同一次动作中补足水位，减少成熟等待。这里的比较包含实际水消耗，但不要求补产其他材料。重置榜需另行核算水的到达时点与费用，不能直接迁入这个充足库存结论。
