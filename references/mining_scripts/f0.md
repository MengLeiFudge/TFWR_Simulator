# f0：5×5、25 机持续下挖

停止原程序后，在游戏中运行已有的 `f0.py`。运行需要至少 25 台无人机容量。脚本先调用 `set_world_size(5)`；实际大小变化时，游戏会重置地形和无人机位置。程序结束后，游戏取消这个大小限制。

主机沿 5×5 地图逐列派出 24 台无人机，再在最后一个位置参与挖掘。25 个位置各一台，每台始终在原地向下挖。某台遇到不可挖的方块或挖掘失败时，输出位置并停止该机，其余无人机继续工作。手动停止程序可结束全部挖掘。

派发时如果生成或移动失败，会提示停止程序、检查帽子或地形后重新运行。已经派出的无人机仍可能继续挖，需用游戏的停止按钮结束它们。

`f0()` 负责大小和派发，`dig_column()` 只负责持续下挖。这是固定位置下探的临时脚本。煤、铁与其他方块均由实际 `dig()` 收集；周围塌方清掉的方块不计入采矿收入。发现煤铁后同层追矿的方案另行研究。

本版本按静态代码、Python 语法和当前游戏 API 检查。实际 25 机采矿运行尚未验证；本地模拟器尚未覆盖地下机制。
