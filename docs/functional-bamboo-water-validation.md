# 常规竹子：筛选期补足水位

2026-11-12。全科技含DLC、普通32×32田、32台无人机、19项资源各10亿；其他材料充足，按实际竹子净增长÷实际游戏秒×60比较，包含筛选、成熟、移动、切收、回收及重派。每例预设10墙钟秒，最多两例并行；35份报告最长1.93墙钟秒。450游戏秒样本现实约1.8～1.9秒，没有延长计算预算。

## 当前实现

`bamboo.bamboo_batch`只在`not ready`的首次花节筛选阶段调用`bamboo_water(0.75)`，低水位时一次用四桶；种植或浇水后仍恢复到高度4再继续筛选。全部竹桩选好后，连续切收沿用原有低于0.25时单桶补水、3游戏秒间隔和4/8/1三个高度。正常5亿库存批次全部工人返回后，再以`ready=True`重派，保留已选竹桩，不重新清场。

正式源只改这一处调用。采用依据是增加1亿及原有5亿批次的三seed实际净速率都严格提高；收益主要来自减少首次筛选的成熟等待，不声称无限期稳态提高。

## 全程高水位候选未采用

另一个代表把筛选和切收全部改为0.75。其首60秒和增加1亿目标都更好，但450秒seed2净增从763498240降到749015424（-1.90%），另外两个seed只有+0.23%/+0.11%。这组结果不足以支持持续生产替换，保留原始报告而不迁入。当前采用版保持后续切收原有补水方式，没有调整巡回路线、间隔或收尾阈值。
