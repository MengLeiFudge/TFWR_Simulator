分析日期：2026-10-22。基于[排行榜缓存](leaderboard_targets.md)、当前脚本及同名策略记录；本次未重跑全部榜单，也未修改策略实现。#10 是预算基准，#1 只作参考。表内本地时间是已有记录，不能直接视为当前文件的最新成绩。

后续进度（2026-10-23）：本地模拟器已完成主要方法/作物机制验收，见[验证范围与误差](../../mechanism_model/local_simulator/validation.md)。下表仍是研究队列，尚未据此改写策略或重测全榜；模型预测用于粗筛，具体策略时间仍须实机确认。

## 已有记录排除了哪些简单改法

- [Fastest Reset](lb_fastest_reset.md)：阶段记录中，Megafarm 3 约 3546 秒、金币一百万约 6636 秒、Dinosaur 3 约 6993 秒，最终约 9984 秒。#10 整轮预算只有 1966.927 秒；即使末尾骨头阶段免费，前面仍超预算。Power 阈值、单项解锁上限、大批次奇异物质及临时过桥路线已有失败记录。提前生产少量骨头换 Polyculture 升级只是待建模假设，必须计入提前解锁和生产成本。
- [Sunflowers Single](lb_sunflowers_single.md)：高花瓣优先、严格最大值、排序/桶缓存等路线已因降低单位时间收割数量而失败。浇水阈值和少量判断调整不足以解释 2.471× 差距；不能把历史“候选方向”直接当作尚未尝试的方案。
- [Maze](lb_maze.md)：已有阶段记录大致为探索 8–12 秒、后续求解 80–90 秒。只消除探索也达不到 42.777 秒。静态区域归属、分派/锁、自然出生等已有失败或小幅收益记录；下次候选须明确减少哪些移动。
- [Carrots Single](lb_carrots_single.md)：四锚点、2×2 support、记忆命中和近距离重写已经实现。缩小/扩大距离阈值及选择性重写已有失败记录。收益必须来自有效伴生周期，而不是单纯减少分支。
- [Dinosaur](lb_dinosaur.md)：已有统计 `cycle_finish` 占约 62.77%，`chase_fill` 占约 22.03%。当前动作模型按空格索引抽苹果，原版先取 x/y 再拒绝占用格；同分布不等于同 seed 轨迹。当前脚本参数与部分旧基线记录也有版本差异，应先校准再做近似候选比较。
- [Cactus](lb_cactus.md)：已有完整统计参考为 198 轮、平均 36.493 秒。邻接逆序交换量是重要下界；现有记录中朴素成对、行列融合、桶与路由等多条路线未胜出。measure 等廉价调用不是约 48% 的缺口来源。

剩余榜按 #10 差距依次为 Wood 1.707×、Maze Single 1.633×、Sunflowers 1.597×、Hay 1.554×、Cactus Single 1.448×、Carrots 1.289×、Wood Single 1.264×、Pumpkins Single 1.164×、Pumpkins 1.116×、Hay Single 1.025×。当前目标是先研究大差距，暂不优先围绕最接近 #10 的榜微调。

## 本地模拟的实际能力与下一步

当前有 Cactus、Dinosaur、Companion 的 C# 动作模型，以及可运行受支持游戏脚本的 Python 农场模拟器。后者不保证任意游戏语言语义或完整轮时间精度，也没有自动接入实机命令前的预测阶段。

本轮独立 Python RNG 实验与真实游戏的 2688 个观测值全部相同，详见[随机数对齐研究](../../mechanism_model/randomness.md)。随机数算法可复刻；剩下的困难是初始化、随机调用次数、事件计时、脚本 tick 与调度。

研究大差距榜单时，可并行保留一个小范围的模型校准目标：先用 Cactus 固定图验证动作轨迹，再处理 Dinosaur 的拒绝采样；之后再扩展需要成熟/伴生事件的模型。这是模型建设顺序，不改变榜单研究按 #10 差距排序的原则。

任何模型输出都标为预期。只有候选机制预算接近 #10、经过真实游戏完成轮及足够统计后，才更新最快实现和本地成绩索引。
