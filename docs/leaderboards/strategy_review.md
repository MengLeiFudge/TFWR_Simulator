# 策略研究优先级

所有榜以当前公开#1为优化目标，#3、#10及前排分布作实现水平参考。按实机／模拟较好时间距#1的比例排序，在差距相近时比较预期收益、证据和验证成本。最新公开事实以[进度总表](leaderboard_progress.md)及[逐榜来源](../../references/leaderboards/status_snapshot.md)为准，具体策略、失败和版本见同名`lb_xxx.md`。

## 三阶段计划

| 阶段 | 目标与范围 | 完成依据 |
| --- | --- | --- |
| 一 | 除两项快速重置外，28榜全部进入+100%以内 | 逐榜有效较好时间≤2×#1；本地证明更快后按存档准入同步 |
| 二 | 非重置榜大部分进入+50%以内，全部榜有真实提交排名 | 非重置明显多数≤1.5×#1；缺记录者必须实机提交，已有记录仅模拟更快时安排复验 |
| 三 | 两项快速重置均进入+50%以内 | 迁入成熟单项结果，比较完整科技路线、混采、筹资和资源补给 |

默认按阶段推进；用户明确指定当前榜或改动时执行其范围。每阶段结束前刷新所用#1和账号记录再核算；刷新失败保留原日期，不声明完成最新榜单目标。比例按原始精度计算，2倍是+100%，不是优化终点。

## 当前重点

以[进度总表](leaderboard_progress.md)为准。当前第一阶段的差额集中于恐龙；下一批比较多机仙人掌、炸药双榜和金字塔多机的生产结构。单榜报告里的局部净收益，等迁入重置初始场景重算供料与机器采购后，再用于重置预测。

| 榜单 | 当前主成本 | 下一项应回答的问题 |
| --- | --- | --- |
| [恐龙](lb_dinosaur.md) | 后半盘固定梳形回路的每果路程 | 哪种可恢复的走廊和短切能减少大多数果实的路程，并通过原版随机满盘？ |
| [仙人掌多机](lb_cactus.md) | 连通组件密度与排序动作 | 能否在两轮内达到收获目标，且多出的换位费用小于省去一轮的费用？ |
| [炸药多机](lb_dynamite.md) | 分区信息传播及扫尾 | 能否从已知安全区域并发推进，在不漏雷的前提下提前结算？ |
| [金字塔多机](lb_pyramids.md) | 定位、横向清土与维修依赖 | 能否合并可独立完成的竖井、探边工序并保持定位可靠？ |
| [迷宫多机](lb_maze.md) | 新宫生成节奏与驻点命中率 | 新驻点布局能否减少重建次数；该效果在重置榜需自筹的异物预算下能否兑现？ |

差距>+100%时默认先比较不同收益机制、规模、分工和兑现路径，不无界调参。明确指定的现有算法优化仍须实现最小代表、按同条件对照并采用有效改善。具体步骤及置信度要求见[策略选择与淘汰](README.md#策略选择与淘汰)。

## 两项快速重置

[普通重置](lb_fastest_reset.md)与[地下重置](lb_fastest_underground_reset.md)分别保存科技链、里程碑、库存与未采用路线。成绩和排名只在[进度总表](leaderboard_progress.md)展示当前值。普通榜的 24:49 清单保留作同路线对照；新的采购组合按最终解锁耗时独立筛选。

两条路线的主要差距仍在前期发展与投资链。每次调整先按[科技路线计价](README.md#重置榜的科技路线计价)从最终实际付款倒推：记录当时净速率、混合产出与可用时点，比较少采、提前升级、推迟升级和不升级。新增投资用真实筹资成本与剩余受益需求比较，再执行完整组合；不能只将末段除以科技倍率。

早双机、低科技伴生、轻矿物包、藏宝图筹金、功能组件直接迁入等具体失败只排除所测支付顺序或实现，结论与代码保留在两份单榜文档。骨头仅允许一顶有效恐龙帽，多蛇并行立即按机制排除；地下终点只需20万竹子和2万炸药，不照搬普通Reset金币／骨头终点。

## 记录与验收

公开榜／账号事实归公开缓存，本地最好模拟及方向归`leaderboard_progress.json`。有效结果后更新对应单榜页并离线重建进度与公开快照。原始批次报告放`.codex/`，不新建跨榜阶段文档；复用结论进入共用方法，历史和失败代码归[历史库](../../references/leaderboard_history/)。

本地模拟不等于公开排名，短筛不等于官方完整统计。实机满足用户明确授权，或有效模拟≤2×#1且快于账号记录；已有记录不因更新文档而重复实机。覆盖与误差以[C#验收](../../simulator/headless/validation.md)为准。
