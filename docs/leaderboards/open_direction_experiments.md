# 已列开放方向的固定代表实验

本批逐项执行此前列出的21个开放方向。共保存27份原生模型报告：21个方向的代表、干草/木头的两个单机补充、三个同输入对照，以及恐龙桥接的一次结构修正。每个代表固定seed1、源码、场景和有限预算；没有扫描常数或增加种子挽救负例。原始证据索引为`.codex/leaderboard-sol/open-directions/index.md`，完整执行源、SHA、原报告、费用、收益分布与库存核对见同目录各实验的`manifest.json`、`seed1.json`、`analysis.json`及汇总`results.json`。

“组件”只记录组件经过的游戏秒与净库存，不填完整预测列。所有27个命令正常返回模型报告；全局插入在预先声明的120游戏秒门槛处主动结束，不曾达到完整目标。全部正常结束的模型spawn/wait配对、库存非负，无模型错误、警告或丢输出。模型自身尚未覆盖的随机交互、并发与计时限制仍以各原报告limitations和模拟器验收文档为准。
