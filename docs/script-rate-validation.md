# 功能算法、速率与成就条件

当前20项功能入口的产出表归[功能脚本](../scripts/functional/README.md#当前产出速率)，24个专用成就入口的时长归[成就脚本](../scripts/achievement/README.md#成就与运行时间)，111项官方名称与入口映射归[完整成就映射](../scripts/achievement/README.md#完整成就映射)。本页保存采用机制、对照结论和适用边界，不另建单次验证MD／JSON。

## 条件与口径

当前数据使用C#原版语言、调度和动作模型，`preset=all`、普通32×32田、全科技含DLC、最多32机，19项可用物料各10亿。其他材料生产时间不计入独立入口速率，动作仍真实消耗材料；全科技不等于无限库存。普通田与排行榜专用场景分别记录，奖励帽不属于全科技。

功能表采用seed1，速率为`实际净库存变化 × 60 / 实际游戏秒`，包含初始化、Jump、移动、成熟、同步及正常结算。只列正增长，水肥自动补给不算产出。多数入口观察60游戏秒，蘑菇120秒，竹子450秒覆盖首个500M重派边界；仙人掌取两批69.78114198秒；金字塔新增5000能量完整目标127.346秒；恐龙完整结算一轮。有限窗口不证明无限期稳态。

多数候选每例先给10墙钟秒；恐龙完整周期预设30秒，seed1实际11.62秒完成684.089游戏秒、入库33488928 Bone。预算到即按实际推进时间和净库存报告，不为凑固定游戏时长放宽；恐龙等未结算批次不能推算效率。初次775.38／697.52秒与截断观察属于旧版本，当前数据不混用。

每次采用前冻结基线、候选、依赖、模型和初始条件，保留seed、实际时间、停止原因与净库存；原始报告和场景留`.codex/`，核心数值与结论写入本页或对应单榜文档。游戏语法与替换要求见[脚本准入](script-validation.md)。本次文档整理没有重新模拟或实机运行，下列均为已有证据归并。

## 仙人掌窗口与收尾

`sort_one_way`只在同次单向扫描中复用相邻三格窗口的两格，交换时维护缓存，并用单调位置替换边界max／min；不跨行、方向或批次。三seed一批／两批六组完整配对净速率提高0.560%～0.578%，measure约少59%，实际物理动作次数相同。

随后全田排序并回收后就地收割，有限目标已达便返回，继续生产才回原起点。一批三seed净速率提高1.359%～1.637%，两批提高0.098%～0.105%，种植、测量、交换和收割次数相同。当前两批实际69.78114198秒净增67108864，速率57702292.13／分钟；上一阶段同口径57645723.13／分钟。

此前60秒窗口只结算一批，显示33554432／分钟，不能将改用两批完整窗口后的展示增长当作算法提升。三seed80秒窗口均仍只收两批，有限收尾收益不外推稳态。

同盘预规划保持相同32行数值、交换顺序与列API，少636次move却多216205解释器节点，完整行阶段33.95953683→34.03394055秒，慢0.219%，未采用。行列交换已接近所选排序顺序的逆序下界，进一步节省须改变目标偏序或实际移动，不仅少查询。

## 普通地形深钻与勘探

煤、铁、石英、石化南瓜统一调用`mining.mine(item, target)`，单爆破钻连续向新地层深入，不反复重生浅田或横向追脉。每次开挖前检查库存目标与炸药；无后台子机，实际爆破掉落入库才计产量。

| --- | ---: | ---: | ---: |
| 煤 | 1360 | 15334 | 5.63～11.28× |
| 铁 | 35952 | 213040 | 4.30～7.01× |
| 石英 | 17752 | 139904 | 4.81～10.79× |
| 石化南瓜 | 670208 | 3823104 | 2.60～5.70× |

对照均为相同全科技、普通田、初始库存及seed的60游戏秒。煤、铁、石英由`resources.materials`预备2000份炸药，铁不再另筹勘探煤；炸药0、煤目标新增500的调度样本先产炸药，再深钻至煤净增732，40.65游戏秒返回且只剩主机。已满足目标时五入口共0次挖掘；炸药0时煤与建材也不挖掘。

`block.py`独立保留采矿大师的60秒库存窗口。补炸药耗尽检查后seed1为1474855／分钟，较上一版1476502少约0.11%，属于缺料正确性修正。当前49.37秒窗口实际净增1044581；早期实机request491为42.42游戏秒净增1050173。滑动窗口、批量掉落及探测返回值见[建材与勘探](block-mining.md)。

## 成就条件

Steam官方简体中文schema共111项：29项专用成就对应24入口，76项常规复用，2项排行榜复用，4项手动科技／UI。官方名称、说明、API ID与来源保存在[原始schema](../references/achievements/steam-schinese.json)，分类与入口保存在[成就目录](../scripts/achievement/README.md#完整成就映射)。

| 炸药排除专家 | 深度≤−600、32×32完整揭开哑弹才正常解盘；专用入口禁止部分结算，无确定安全格换田。当前依赖三seed63.40／204.17／239.73秒，均回收全部子机 |
| 金字塔相关 | 原生最小底边5、体积35，彩色塔用6格田的5格原生塔，不能人造3格代替；大金字塔需随机29格塔，不承诺5分钟 |

24个专用入口已有seed0／1／2共72次本地验证，22个正常结束，2个按预期报错，均在300游戏秒内且结束只剩主机。模型不读取Steam解锁状态，`finished`不等于账号已获成就；结束时田尺寸可能被游戏恢复，应看动作与完成前输出。后续源码或依赖变化仍须重新验证。
