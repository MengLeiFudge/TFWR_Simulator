# 策略研究优先级

所有榜以当前公开#1为优化目标，#3、#10及前排分布作实现水平参考。按实机／模拟较好时间距#1的比例排序，在差距相近时比较预期收益、证据和验证成本。最新公开事实以[进度总表](leaderboard_progress.md)及[逐榜来源](../../references/leaderboards/status_snapshot.md)为准，具体策略、失败和版本见同名`lb_xxx.md`。

## 三阶段计划

| 阶段 | 目标与范围 | 完成依据 |
| --- | --- | --- |
| 一 | 除两项快速重置外，28榜全部进入+100%以内 | 逐榜有效较好时间≤2×#1；本地证明更快后按存档准入同步 |
| 二 | 非重置榜大部分进入+50%以内，全部榜有真实提交排名 | 非重置明显多数≤1.5×#1；缺记录者必须实机提交，已有记录仅模拟更快时安排复验 |
| 三 | 两项快速重置均进入+50%以内 | 迁入成熟单项结果，比较完整科技路线、混采、筹资和资源补给 |

默认按阶段推进；用户明确指定当前榜或改动时执行其范围。每阶段结束前刷新所用#1和账号记录再核算；刷新失败保留原日期，不声明完成最新榜单目标。比例按原始精度计算，2倍是+100%，不是优化终点。

## 两项快速重置

用户已单独要求推进双重置。当前[普通Reset](lb_fastest_reset.md)本地三seed均2479.105836秒、账号2507.696秒；[地下Reset](lb_fastest_underground_reset.md)采用源八seed均3034.092696秒，有效更快候选八seed均3026.821846秒、账号3279.570秒。候选均值与采用版本分别保留，历史前三seed更乐观结果不替换较大共同样本。

两条路线的主要差距仍在前期发展与投资链。每次调整先按[科技路线计价](README.md#重置榜的科技路线计价)从最终实际付款倒推：记录当时净速率、混合产出与可用时点，比较少采、提前升级、推迟升级和不升级。新增投资用真实筹资成本与剩余受益需求比较，再执行完整组合；不能只将末段除以科技倍率。

早双机、低科技伴生、轻矿物包、藏宝图筹金、功能组件直接迁入等具体失败只排除所测支付顺序或实现，结论与代码保留在两份单榜文档。骨头仅允许一顶有效恐龙帽，多蛇并行立即按机制排除；地下终点只需20万竹子和2万炸药，不照搬普通Reset金币／骨头终点。
