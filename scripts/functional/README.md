# 功能脚本

本目录保存直接在游戏内运行、持续获取目标资源的脚本。目前尚无正式实现；下列文件名是命名示例，不表示已有可用脚本。

## 命名

使用小写英文和下划线，保证文件名可直接用作游戏模块名。资源生产脚本直接按资源命名；需要区分机制时使用 `资源_机制.py`。

| 用途 | 文件名示例 |
| --- | --- |
| 水稻 | `rice.py` |
| 木材 | `wood.py` |
| 恐龙产骨头 | `bone_dinosaur.py` |
| 迷宫产金币 | `gold_maze.py` |
| 藏宝图产金币 | `gold_treasure_map.py` |
| 金字塔产能量 | `power_pyramids.py` |

## 运行约定

- 用户运行入口后持续生产目标资源，不以排行榜目标库存为停止条件，不调用排行榜计时入口。
- 入口函数与文件同名，直接执行文件即可调用入口。依赖、必要资源及解锁前提在脚本说明中列明。
- 根据当前解锁、科技等级、可用地块和无人机数量选择可执行方式；低科技阶段采用可用方案，高科技阶段利用已解锁能力。不默认满科技、32×32 地图或 32 台无人机。
- 对种植材料、消耗品和其他必需资源处理补给。机制本身未解锁且无可行替代，或缺少无法自产的前置资源时，明确说明条件后停止，不空转，也不调用尚未解锁的 API。
- 新实现先用本地模拟验证代表性的科技阶段、资源不足和地图边界，再按授权进行实机对照。模拟器尚未覆盖的条件必须列明，不能宣称已经适配。

排行榜脚本另存于 [../leaderboard](../leaderboard/README.md)。可参考其成熟机制，但只有符合上述运行约定的实现才能作为功能脚本交付。部署仍遵守仓库的真实存档边界；现有 `sync_leaderboard_scripts.py` 只处理排行榜脚本。
