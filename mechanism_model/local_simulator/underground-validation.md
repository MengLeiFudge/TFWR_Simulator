# 地下模拟的逐项实机对照

本阶段实现悬浮高度、普通地下区块、挖掘与塌方。每个用例将同一份 `probe.py`、显式科技和库存、相同 seed 分别交给本地运行器与游戏 `simulate()`。正式排行榜使用另一条生成路径，本记录不代表地下榜单或全部 DLC 已通过。

## 实现与范围

- `world.py`：`hover/get_hover/get_pos_z/get_hardness/get_stability/dig`，悬浮高度的动作重置和地下状态快照。
- `underground.py`：16 层区块、逐柱深度、普通地层硬度和稳定性、塌方传播。地形未实现时抛出 `NotImplementedError`，不把特殊地形替换成普通土。
- `noise.py`：原版 OpenSimplex 的二维、三维贡献表、Int64 洗牌与 Double 累加；地层计算在原版 Single 运算位置舍入。
- `randomness.py`：基础八流后追加 `worldGen`、`bamboo`；每次重建消耗地形种子及两个噪声种子。
- `underground_resources.json`：从游戏资源提取科技、物品、地面和特征顺序。存在枚举或科技数据不表示对应机制已实现。

科技预设 `max` 保持基础游戏全满，DLC 科技默认 0。通过场景显式启用，例如：

```json
{"preset":"max","unlocks":{"Mining":1,"Underground_Senses":1,"Bamboo":1},"items":{"Pumpkin":1000000000,"Power":1000000000}}
```

`dig()` 只接受零参数。硬度和稳定性方向查询不环绕，越界返回 `None`；`get_pos_z(direction)` 环绕，返回地层深度的负数，不含悬浮高度。挖掘按硬度、执行速度和 Mining 等级计时，动作本身不耗 Power。被塌方移除的块不发放掉落。

## 已完成的同 seed 对照

游戏构建 26410308；Core/Utils 和资产指纹保存在资源文件中，报告另列 `underground_model_version`，不覆盖基础模型的版本事实。

| 用例 | seed | 请求 | 输出检查点 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 悬浮及动作重置 | 1 | 283 | 39 | 返回值、高度、tick 与末尾时间一致 |
| 4×4 连挖 28 层、巡视与清场 | 1 | 285 | 126 | 地形、深度、硬度、稳定性、掉落、tick 一致 |

| 同一双机脚本 | 2 | 288 | 83 | 同上；完整返回时间一致到整数纳秒 |

共 457 条脚本输出。六处时间文本因 Python 浮点打印产生小于 0.000003 ns 的差异；两处 Power 仅比较到游戏显示的两位小数，本地分别有约 0.0035 的余数。其余输出逐字相同。每个用例末尾 `get_time()*1e9` 检查点一致。

请求 288 的本地完整时间与游戏 `simulate()` 完整返回值均为 **4,550,478,840 ns**。前四次请求的完整返回值仅保留游戏 0.01 秒显示，不能据此声称完整返回时间精确到纳秒。

证据位于 `.codex/dlc-sim/`：各用例的 `probe.py`、`scenario.json`、`seedN/local.json`、`outputs.json`、完整请求报告、`comparison.json` 与 `restoration.json`；总比较为 `comparison.json`。对照工具为 `run_pair.py` 和 `compare.py`。

请求 282 因驱动漏开 Bamboo 解锁失败；请求 284 验证出公开 `dig()` 拒绝方向参数。两项已修正后重新实测，失败记录保留。成功请求的 BepInEx/Unity 日志没有新增错误；已有 `test.py`、`simulate.py` 均在终态回到 idle 后逐字节恢复。

## 尚未验收的边界

- 本阶段实机用例未开启矿脉、稻米、蘑菇等特殊地形；通过的是普通地层循环。硬块生成、深层岩带及二维噪声已有代码，尚未单独实机对照。
- 竹子实体、生长、花位和入格切割尚未实现；悬浮仅验证普通作物及恐龙帽交互。
- 稻米、蘑菇、炸药、矿石勘探、放块、金字塔、藏宝图和地下 Reset 尚未实现。
- 地下正式榜单的特征白名单和虚拟深度尚未接入。当前科技目录不代表这些解锁的全部副作用均已支持。
- 任意帽子/特殊实体与挖掘组合、全部错误参数、长程策略时间精度尚未验收。

后续继续按单机制实现、同脚本同 seed 实机对照推进；不将本阶段短程一致推广到全部地下行为。
